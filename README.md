## What connects the work

I’m interested in the whole product: the interface people use, the rules behind it, how information is saved, and how updates reach users. I use AI-assisted development alongside product design, hands-on review, and iterative testing.

**Across these projects:** JavaScript · Node.js · HTML/CSS · Java · SQLite · Cloudflare Workers/Pages · D1 · R2

The portfolio includes project details, screenshots, public links, and clear release status. Data Architect is my separate business website, where I publish product walkthroughs and explain the work behind the tools.
